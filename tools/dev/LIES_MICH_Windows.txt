HALT KURS  -  Windows-Fassung
==============================

Starten: "Halt Kurs.exe" doppelklicken. Installation ist nicht nötig, die Datei ist in sich vollständig.

Beim ersten Start warnt Windows ("Der Computer wurde durch Windows geschützt"), weil die Datei nicht
signiert ist: auf "Weitere Informationen" und dann auf "Trotzdem ausführen" klicken.

Bedienung (kurz)
  Klick auf einen Knoten der Seekarte (rechts) oder Q / W / E   Kurs wählen
  1-3 / 4-6 / 7-9                                              Segel / Ruder / Küste einstellen
  Enter oder "Auslaufen"                                       eine Fahrt fahren
  C / B                                                        Mannschaft / Schiff und Werft
  H                                                            Hilfe im Spiel
  M, + / -                                                     Musik an/aus, Lautstärke
  F11                                                          Vollbild
  Esc                                                          Hauptmenü

Spielstand, Gedenkstein und Einstellungen liegen in:  %APPDATA%\Halt Kurs v2
(Ordner löschen = ganz von vorn anfangen.)

Musik: Diese Fassung enthält die vier Hintergrundstücke (See, Sturm, Schlacht, Hafen). Die Lieder mit Gesang
(Hauptmenü, Untergang) sind nicht dabei; dann bleibt das Menü stumm. Effekte sind vollständig.
